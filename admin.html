Form Lead & Tích Hợp

Gửi lead về email và đồng bộ Google Sheet
Nhận Lead Qua Email
1 Tạo tài khoản Formspree.io (miễn phí, không cần code)
2 Tạo form mới → copy Form Endpoint URL (vd: https://formspree.io/f/xyzabc)
3 Dán URL vào ô bên dưới → Lưu → Form tự động gửi email khi có lead mới
Để trống = form chỉ hiện thông báo thành công
Email sẽ nhận tất cả leads
Đồng Bộ Google Sheet
1 Mở Google Sheet → Extensions → Apps Script
2 Paste code từ nút bên dưới → Deploy → Web App URL
3 Dán Web App URL vào ô dưới → Lưu là xong!
Paste URL sau khi deploy Apps Script

Kết Nối GitHub

Lưu nội dung & upload ảnh lên GitHub → Netlify tự deploy
1 Vào github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
2 Bấm Generate new token → chọn scope: repo (toàn bộ) → Generate
3 Copy token dán vào ô bên dưới → Bấm Lưu & Kiểm Tra
4 Từ giờ bấm 🚀 Publish lên Web là website tự cập nhật trong ~30 giây!
Token được lưu trong trình duyệt của bạn, không gửi đi đâu ngoài GitHub
Chưa kiểm tra kết nối
Hướng dẫn kết nối Netlify ↔ GitHub (auto-deploy)
1 Vào app.netlify.com → chọn site vutrongkhai-landing
2 Site configuration → Build & deploy → Link repository
3 Chọn GitHub → chọn repo khaibaodai/vutrongkhai-landing
4 Branch: master, Build command: (để trống), Publish directory: . → Save
✓ Từ đó mỗi khi bấm Publish trong admin → GitHub cập nhật → Netlify tự deploy trong ~30 giây!
